## Consumer lifecycle

Provide an implementation of `PolicyClock::current()` returning a `TrustedCut`: the genuine root-signed current policy, an optional conservative time interval, and an injected trusted time floor. This callback MUST belong to trusted local configuration. `Query` and `Begin.current` are not its source. `None` time or a time/policy regression refuses current authorization. The provider retains observed policy/time floors only in this process; B2 must couple them to the qualified physical host before any restart guarantee.

Construct `EvidenceConfig` with the exact descriptor, full identity, root public key, private node seed, finite `DecodeLimits`, genuinely root-signed certificate catalogue, and finite session capacity. `GenuineEvidence::new(config, source)` validates the namespace and catalogue or returns `Fault`. `register_certificate` admits a distinct valid canonical origin; exact repeats are idempotent, changed/reused origin/epoch/issuance records refuse. Capacity exhaustion refuses new registration without replacing old custody.

For every local request/connection, obtain the actual channel/session binding from the trusted local ingress. Call `issue_challenge(SessionRequest)` with the requester, writer public key, exact operation digest, channel, fresh nonzero session/challenge nonces and finite window. The returned node-signed `LocalChallengeBody` is not append permission. The client signs its exact `LocalResponseBody`, including the signed challenge digest. Call `authenticate(response, actual_channel, actual_session)` on that same provider. Foreign, copied or consumed challenges and replayed responses refuse. Authenticated peer transport does not perform this local writer-possession step.

Pass the complete `BoundQuery` to `verify`. A genuine authenticated operation yields provider-derived `Facts`; callers MUST NOT manufacture Facts. Local verification consumes its own one-use authorization. A second local request needs a fresh challenge/response even for identical operation bytes. Unavailable current observation yields `Verdict::Unavailable`; a retained original continuation must remain owned and B2 must retain its uncertainty. An invalid response or proof yields `Verdict::Invalid`. Authenticated invalid text payload is retained as `payload_valid=false`, never qualified application admission.

For a kernel-issued `AdmissionSeal` query, supply its exact retained `validated_under`, verified facts and bindings to `seal`. The provider checks its own retained verification, recomputes the genuine facts and signs the exact original-admission body. A seal is conditional evidence; it is not a receipt or durable commit. Historical verification uses the original signed policy/permit/admission cut and does not rewrite that cut after current expiry, revocation or clock unavailability.

`observe(instance, identity)` obtains a fresh trusted cut from the configured source and returns the exact policy bytes, node identity and conservative time. `source_mut()` is a trusted-configuration hook, not a client API. `session_custody()` returns bounded retained signed challenges/responses for the future B2 coupling. It does not restore them, persist them, or authorize clearing consumed flags. This adapter has no disk `open`, `close`, restart or enrollment command. Drop ends only its in-process custody; consumers cannot infer terminal storage outcomes from it.
