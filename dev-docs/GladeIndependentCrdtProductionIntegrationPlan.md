## Outcome and exclusions

and automatic duplex exchange in two actual glade-node processes using the same
production-bound node runtime. One fresh authenticated resource and released text
profile is the bounded initial witness. Each authorized node accepts while partitioned;
reconnect heals exact history/proof identities and text without client ferrying.

This is local development qualification, not live browser activation. IC-4 remains
client/Glial durable intent, compatibility rollout, enrollment, migration and
readiness. No push, desk rebuild/restart, live key/store/launcher change, seal or
existing-resource profile switch is included. Explicit scratch config/keys/floors
are provisioned by the harness. Production values need not block this bounded work.
